# AiSD_Lekcja5
Maciej Kaczmarczyk
Zadanie 5.1

Projekt zawiera implementację struktury danych ADT LIST w oparciu o listę powiązaną podwójnie.

Implementacja została zrealizowana jako szablon klasy DoubleList, operującej na wskaźnikach head oraz tail. Poprawność działania wszystkich metod weryfikowana jest w pliku main.cpp za pomocą testów jednostkowych opartych na funkcji assert().

Jak uruchomić?

Wymagany jest system z zainstalowanym kompilatorem g++ oraz programem make. W terminalu wpisać jedną z poniższych komend:

make run – kompiluje program i od razu go uruchamia.

make – tylko kompiluje program (tworzy plik main.out).

make clean – usuwa pliki binarne i obiektowe wygenerowane podczas kompilacji.
